# Fix columna NP/NV en Técnica > Portones en Acopio

Este paquete mueve y fuerza la columna **NP/NV Odoo** al comienzo de las tablas de:

- Técnica > Portones en Acopio
- Técnica > Acopio -> Producción

La referencia se toma de los campos Odoo ya existentes del presupuesto y se muestra como chip verde.
