# Dashboard - Puertas

Copiar el contenido de este ZIP sobre la raiz del repositorio y redeployar el frontend.

Cambio incluido:
- Agrega el boton Puertas dentro de `/dashboard`, junto a Portones, Ipanel y Otros.
- Usa `catalog_kind="puerta"` para configurar secciones, etiquetas, alias, visibilidad, dependencias, nombres PDF y vista de data.
- Elimina del dashboard la formula comercial vieja de puerta, porque el nuevo flujo usa presupuesto de Puertas como catalogo propio.

No requiere ejecutar comandos ni SQL manual.
