# Resumen inferior en aprobaciones

Se actualiza el detalle de presupuestos para aprobaciones comercial/técnica.

Cambios:
- En Datos comerciales se agrega el monto del coeficiente aplicado.
- Debajo de la tabla de ítems se agrega una tarjeta Resumen del presupuesto.
- El resumen muestra:
  - Base sin coeficiente.
  - Coeficiente aplicado.
  - Monto coeficiente, positivo para recargo y negativo para descuento.
  - Neto.
  - IVA aplicado.
  - Total del presupuesto.
- Los importes usan el mismo cálculo que el presupuestador y el PDF enviado al cliente.
