# Sección final en dependencias

Se agrega configuración de **Sección final** junto a la **Sección inicial** en Dashboard > Dependencias del catálogo.

Uso recomendado para Portones:

1. Ir a Dashboard > Portones > Dependencias.
2. Mantener la sección inicial actual.
3. Seleccionar como **Sección final** la sección donde está el producto Envío 2842.
4. Guardar secciones.

Cuando el usuario edite cantidad/precio de un ítem final como Envío 2842, el cotizador mantiene abierta la sección final configurada en vez de volver a la sección inicial.

No cambia cálculos, PDFs ni envío a Odoo.
