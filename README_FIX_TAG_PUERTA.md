# Fix tags de Puerta desde Odoo

Copiar el contenido del ZIP sobre la raíz del repositorio y redeployar backend.

Corrige la lectura de etiquetas desde Odoo para que el catálogo del presupuestador detecte productos con etiqueta Puerta aunque la etiqueta venga desde campos alternativos de Odoo.

Después del deploy, entrar al Dashboard y presionar Refrescar catálogo.
